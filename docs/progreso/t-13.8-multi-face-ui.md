# T-13.8: Visualización multi-face en frontend

## Estado: Completada

## Descripción

Se implementó la visualización completa de predicciones para **todas** las caras detectadas en una imagen. Antes, el frontend solo mostraba los atributos de la primera cara ignorando el resto. Ahora el usuario puede:

- Ver **tabs** ("Cara 1", "Cara 2", ...) para alternar entre predicciones de cada rostro.
- Ver **bounding boxes numerados** dibujados sobre la imagen de resultados.
- La **cara más grande** (área máxima) se selecciona automáticamente por defecto.

No se modificó ningún archivo del backend. La API ya devolvía `bbox` y múltiples `FaceResult`; el problema era exclusivamente de presentación en el frontend.

## Archivos modificados

- `frontend/index.html`: Agregado `<canvas id="results-canvas">` dentro de `#results-image-container` y `<div id="face-tabs">` entre imagen y grid de atributos.
- `frontend/css/style.css`: `results-image-container` con `position: relative` para overlay del canvas; estilos `.face-tabs`, `.face-tab`, `.face-tab.active` (pills con color primario).
- `frontend/js/app.js`: Nuevas funciones `findLargestFaceIndex`, `renderFaceTabs`, `drawBoundingBoxes`, `renderFaceAttributes`. `showResults` reescrita para usarlas. `clearAll` actualizada para limpiar estado. Listener de `resize` para redibujar bbox al cambiar tamaño de ventana.

## Decisiones técnicas

| Decisión | Elección | Razón |
|----------|----------|-------|
| Canvas overlay | `<canvas>` position absolute sobre `<img>` | Permite dibujar bbox sin alterar el layout de la imagen |
| Selección por defecto | Cara con mayor área (`w × h`) | Corresponde a la cara más cercana/relevante |
| Tabs solo si >1 cara | `if (count <= 1) return` en `renderFaceTabs` | No mostrar UI innecesaria con una sola cara |
| Default `use_largest_face_only` | Se mantiene `True` en `FaceProcessingPipeline` | Decisión del usuario; ese pipeline es para training/preprocessing |
| Resize handler | `window.addEventListener("resize", ...)` | Mantiene bbox alineados si el usuario redimensiona la ventana |
