# T-10.3: Integración MLflow con Model Registry

## Estado: Completada

## Objetivo
Integrar MLflow como backend alternativo para el Model Registry.

## Componente implementado

### MLflowRegistry (`src/facial_attributes/model_registry/mlflow_registry.py`)

Clase que integra MLflow con el sistema de registro de modelos:

- **`log_training_run()`**: Registra un entrenamiento como run de MLflow con métricas, configuración, dataset y modelo
- **`get_run()`**: Obtiene un run de MLflow por ID
- **`get_model_versions()`**: Obtiene versiones de un modelo registrado en MLflow
- **`transition_model_version()`**: Transiciona versiones de modelo a diferentes stages (Staging, Production, Archived)
- **`load_model()`**: Carga modelos PyTorch desde MLflow
- **`delete_model_version()`**: Elimina versiones de modelo
- **`search_runs()`**: Busca runs de MLflow con filtros
- **`get_experiment_summary()`**: Obtiene resumen del experimento

## Funcionalidades

### Logging de Entrenamiento
```python
registry = MLflowRegistry(experiment_name="facial_attribute_recognition")
run_id = registry.log_training_run(
    run_name="train_v1",
    model_name="facial_attribute_classifier",
    version="1.0.0",
    metrics=metrics,
    config=config,
    dataset=dataset,
    model=pytorch_model,
    tags={"author": "team"}
)
```

### Gestión de Versiones
```python
# Obtener versiones
versions = registry.get_model_versions("facial_attribute_classifier")

# Transicionar a Production
registry.transition_model_version("model", "1", "Production")

# Cargar modelo
model = registry.load_model("facial_attribute_classifier", "1")
```

### Búsqueda y Reporting
```python
# Buscar runs
runs = registry.search_runs(model_name="facial_attribute_classifier")

# Resumen del experimento
summary = registry.get_experiment_summary()
```
